# Walraven – rozcestník technických nástrojů

Responzivní webový rozcestník se třemi kartami (Pacifyre, Compensation, Wrap Páska).

## Publikace

1. V repozitáři `dronepilotjs/home` nahrajte `index.html` do kořene větve `main`.
2. GitHub **Settings → Pages → Build and deployment → Deploy from a branch**, zvolte `main` a `/ (root)`.
3. Stránka pak bude dostupná na `https://dronepilotjs.github.io/home/`.

## Jazyky

Čeština, angličtina, slovenština a polština. Při prvním spuštění se nastaví jazyk prohlížeče; ruční volba se pamatuje v `localStorage` daného prohlížeče.

## Logo

Logo načítá stránka z veřejného webu Walraven (`www.walraven.com`). Pokud není dostupný internet nebo zdroj, zobrazí se místo něj textové označení `walraven`. Zbytek stránky je soběstačný bez externích knihoven.

## Odkazy

Adresy aplikací předpokládají aktivní GitHub Pages jednotlivých repozitářů.
